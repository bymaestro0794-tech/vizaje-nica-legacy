# Vizaje-Nica B2B landing

Лендинг для брендов-партнёров (дистрибуция и розница красоты, Молдова). Язык сайта: только английский.
Дизайн готов в Figma, задача: сверстать его на чистом HTML/CSS/JS и добавить анимации.

## Стек

- HTML, CSS, JS без сборщика. Точки входа: `index.html`, `main.css`, `main.js`.
- Lenis: плавный скролл. GSAP + ScrollTrigger: анимации по скроллу. Motion: пружины, hover, layout-переходы, inView.
- Все библиотеки подключены по CDN в `<head>` (см. `index.html`). Они дают глобалы `Lenis`, `gsap`, `ScrollTrigger`, `Motion`.
- Шрифт: Inter (Google Fonts, 400/500/600/700).
- Dev-сервер: `npx -y http-server -p 8934 -c-1` (конфиг в `.claude/launch.json`), адрес http://localhost:8934.

Перед первым использованием проверить в консоли, что все четыре глобала загрузились и версии по ссылкам существуют.

## Структура

```
index.html
main.css            только @import файлов ниже
main.js             только подключение модулей
css/tokens.css      переменные (готов)
css/base.css        reset, типографика, контейнер, кнопки
sections/<name>/<name>.css
sections/<name>/<name>.js
js/lib/lenis.js     инициализация Lenis и связка с ScrollTrigger
js/lib/modal.js     общий компонент модалки
data/brands.js      данные брендов (готов)
img/                картинки (уже в проекте)
docs/               build-plan.md, motion-spec.md
```

Правило: папка на секцию (feature-based), не общая папка на все css и js. `main.js` подключаем как `<script type="module" src="./main.js">`, CDN-скрипты остаются `defer` выше, так глобалы доступны модулям.

## Как работаем

- Один шаг за раз. Не делать несколько секций сразу.
- В ответе показывать только изменённый код, с указанием файла и места (после какого блока).
- Не переписывать файл целиком, если достаточно точечной правки.
- В начале каждой сессии: цель проекта, стек, текущее состояние (см. раздел ниже).
- Токен-эффективно: не пересказывать уже сделанное, не перечитывать без нужды большие файлы.
- Из Figma не копировать пиксель в пиксель, если что-то выглядит неправильно (наезжающие элементы, кривая сетка, странные отступы). Исправлять и коротко сообщать, что изменено.
- Перед каждой секцией сверяться с Figma (ссылки в `docs/build-plan.md`) и со скриншотом результата в браузере.

## Анимации

Полное описание в `docs/motion-spec.md` (оно же на странице «Motion spec» в Figma). Кратко:
- Интерактив только на пружинах Motion (300/30, 120/14, 400/40), без ease и duration.
- Скролл-привязанные сцены только через GSAP ScrollTrigger, Lenis синхронизирован с ним.
- `prefers-reduced-motion`: отключить parallax, scrub, magnetic. Оставить простой fade.
- Анимировать только `transform` и `opacity` (blur точечно).
- Сначала верстка и адаптив без анимаций, анимации отдельным проходом по секциям.

## Текущее состояние

- Готово: п. 1–12. Все секции свёрстаны (1440, 1024, 768, 390), анимации по `docs/motion-spec.md` сделаны во всех секциях.
- Планшет: по макетам сделаны Nav, Hero, Our business, Numbers, Brands, FAQ, Footer. Слайдер, What we offer, Final CTA и планшетные модалки (704/880) решили не делать.
- Точки перелома: ≤767 mobile, 768–1023 и 1024–1279 планшеты (диапазонами, без протекания), ≥1280 desktop.
- Анимации: общие пресеты и хелперы в `js/lib/motion.js` (springs, interactive, magnetic, revealOnView, splitWords). Элементы, которые появляются анимацией, скрыты через класс `.js` на `<html>` (ставится в `<head>`, снимается через 4 с, если скрипты не запустились).
- Данные брендов лежат в `js/brands.js` (не в `data/`). Логотипы: Brandfetch CDN по домену, у кого нет — локальные файлы `img/brands/*.png`, иначе плитка с названием.
- Отступления от motion-spec: нет «перелёта» картинки карточка → модалка (картинка в модалке внизу и обрезается её краями); сборка пазла в What we offer сделана из 4 копий `360.png` с `clip-path`, для чистого эффекта нужны отдельные PNG частей; опциональные skewY и marquee не делали.
